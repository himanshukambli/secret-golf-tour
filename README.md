# Secret Golf Tour Website

Free static website for GitHub Pages.

## YouTube playlist
https://www.youtube.com/playlist?list=PL1m3Bw6VGCWR9OOpL4vE76paeqZqbmM1n

The homepage embeds the playlist directly using YouTube's privacy-enhanced player.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `secret-golf-tour`.
2. Upload `index.html` and `style.css`.
3. Repository → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder `/root`.
6. Save and open the GitHub Pages URL.

## Updating videos
You don't need to edit the website for every new video if you keep adding videos to the embedded YouTube playlist.
